# NaKolace – telefonos rendelések

Webes alkalmazás (PWA) a nakolace.sk telefonos rendeléseinek rögzítésére és kezelésére, laptopon és telefonon.

## Állapot
Tervezési fázis. A követelmények: [SPECIFIKACIO.md](SPECIFIKACIO.md)

## Technológia
- Frontend: PWA, hosting: Netlify
- Backend: Supabase
- Termékadatok: a nakolace.sk Payload REST API-ból (csak olvasás)
